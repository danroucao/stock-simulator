## 交易與成本

- 表單與委託卡片差異已定位為卡片漏傳手續費折數。兩者現在使用 `order-planning.ts` 同一估算入口、目前帳戶成本設定及同一持有天數。保留完整精度，網站最後取整元；Excel 顯示二位小數並保存完整值，不先逐項四捨五入。
- 價格非正有限數、股數非正整數、日期無效或方向錯誤時，相關目標損益、風險及風險報酬比顯示無法計算。缺停損不顯示有效風險、比例或建議股數；數量與交易單位不符時可用風險建議修正數量，但不顯示有效的本單損益。
- 新單保存預計交易日、建立時間、有效至與預估持有日曆天數，各自獨立；預計交易日不得晚於有效至，並排除週末與已知休市日；未知年份僅依週末判斷並提示核對日曆。有效至是日曆期限，可與預計交易日不同。不自動更改輸入日期以掩蓋錯誤。狀態包含尚未到交易日、待成交、部分成交、已成交、已取消及已過期，過期優先。成交日不得早於建立日或預計交易日，也不可晚於有效至或今天。
- 建立、修改、成交及取消立即嘗試儲存；失敗保留本頁資料並明示未成功儲存，可按重試儲存，不宣稱成功。相同表單重送不產生新單；修改條件或明確複製後可以建立另一單。
- 賣出淨損益使用同股票、同類型持倉先進先出的實際進場基準，包含進場費分攤，持有天數截至今天；持倉不足不計算局部損益，不將它當成新的進場至目標價差。

## Excel 與相容性

匯出入口已移到待成交清單旁，空清單亦可查看匯出設定。可依全部／目前股票、預計交易日及是否含過期單篩選。舊單交易日缺漏不推測；指定日期時不納入未設定日的舊單。

保留原 H、I、J、M 等價位、股數、委託金額與價差損益欄位位置；12,000 元未扣成本價差測試維持正確。新增交易日、持有天數、各成本、預估淨損益、費率、折數、最低費、年率與網站狀態。買進總覽的價差／成本及全部已知淨損益與明細核對；任何淨損益未知時，淨合計留空並列缺漏筆數。賣出列使用持倉成本，明示與買進不同的估算基準。Excel 手填狀態不會回寫網站。

既有 localStorage 工作區仍是版本 1，只增加選填欄位，不覆寫舊單日期。舊單成本沿用原天數，提示可編輯確認；編輯舊單可保留未設定交易日，複製成新單則需確認新日期。備份匯入檢查新增日期與天數，包含已結束委託；原備份仍可還原，不需破壞性遷移。

## 選股、提醒與路由

範圍仍由搜尋、市場及產業組成；快速策略保留範圍。可逐一移除條件、重設全部或儲存，選中策略以勾號與文字／樣式表示。所有條件仍以 AND 判斷；空結果不自動放寬，提示移除條件。

手機使用原生 dialog 篩選抽屜，支援焦點限制、完成與 Escape 關閉；桌面保留直接操作。清單依盤整／波動／均線目的突出相關資訊，其餘可展開；均線與可用性原因沿用既有功能。接近上緣限定目前仍在保存區間內；距上緣排序也先排有效區間觀察，跌破或突破後的股票不當成候選。

長清單在離開路由前保存捲動位置，避免 DOM 移除後高度縮短覆蓋記錄；待資料渲染後才恢復。路由一般頁面的上／下一頁位置由 Shell 處理，選股、市場與提醒清單自行恢復，同步篩選 URL 不重設捲動。已驗證 40 檔返回及重整時保留筆數、條件與原位置。非同步還原有銷毀守衛，不在切到另一頁後跳動視窗。

提醒頁籤改稱持續觀察，說明突破／跌破後已離開原整理區間；原區間只作追蹤依據。直接開啟個股時立即綁定委託股票代號，延遲行情不重設已編輯的同股票草稿。一般個股不顯示未選中的提醒事件；圖表仍按個股下載，載入文案包含股票名稱。站內私人條件沿用首次基準、新符合、離開、資料不足及僅開啟瀏覽器比較的既有語意。
